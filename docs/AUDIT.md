## ما يلزم قبل الإطلاق

1. **البريد الحقيقي:** إعداد SMTP وتجربة وصول رابط الاستعادة للطالب والإدارة، ثم استخدامه. الفحوص البرمجية لا تثبت وصول البريد إلى صندوق حقيقي.
2. **بيئة التشغيل:** تحقق MySQL 8.4 وPHP 8.4/Docker، وصلاحيات التخزين والنسخ الاحتياطي على الجهاز أو الاستضافة. لم يتوفر Docker/MySQL في بيئة الفحص المحلي.
3. **عنوان الموقع والحماية التشغيلية:** `APP_URL` الصحيح، HTTPS، إيقاف debug في الإنتاج، حفظ الأسرار خارج Git، وتقييد Host وخادم الويب إلى مجلد `public/`.
4. **اختبار قبول:** تجربة البيانات الحقيقية والأدوار الثلاثة على الأجهزة والمتصفحات المستهدفة، وتجربة استعادة نسخة احتياطية.

## تحسينات اختيارية لا تمنع عرض المشروع

- صفحات أخطاء 404/419/500 بتصميم ولغتين متناسقتين؛ يستخدم المشروع حاليًا صفحات الإطار الافتراضية للحالات غير المتوقعة.
- اختبار ضغط وتزامن على MySQL بحجم الاستخدام المتوقع، خصوصًا بدء المحاولات وملفات الاستيراد الكبيرة. حد 1000 سؤال يطبق بعد قراءة الملف، فلا يثبت وحده أن استهلاك الذاكرة محدود لكل ملف مضغوط.
- مراقبة تشغيلية وتنبيه للأخطاء وسياسة احتفاظ بالسجلات والنسخ الاحتياطية حسب الاستضافة.

لم تُضف متطلبات وظيفية جديدة مثل مؤقت للاختبار أو ترجمة محتوى الأسئلة أو صلاحيات منفصلة لكل مقرر؛ هذه ليست ضمن نطاق المشروع المتفق عليه. لم تُقس نسبة تغطية السطور، ولا تُساوى أعداد الاختبارات بضمان تغطية جميع الحالات.
